Privacy

This page covers two different things that share a name: the website you are reading, and the application you install. Both are short to describe, because neither of them collects anything.

This website

Every page here is a static file served by GitHub Pages. There is no backend, no database, no login and no form that submits anywhere.

  • No analytics and no advertising. No Google Analytics, no Plausible, no pixel, no heat-map script, no tag manager. Nothing on this site reports that you were here.
  • No cookies. The only thing stored in your browser is one localStorage entry, ice-theme, which remembers whether you chose the light or dark theme. It stays on your machine, is never sent anywhere, and you can clear it like any other site data.
  • Two requests leave your browser, and you can see both of them in your browser's network panel:
    • A read-only GET to api.github.com for the project's public release list, which is what fills in the version badges, file sizes and download counts. It carries no identifier, no cookie and no personal data — it is the same public, anonymous request anyone's browser makes when visiting a GitHub releases page.
    • A request to github.com or its download host, only when you actually click a download link.
  • No fonts, no CDNs, no third-party scripts. The stylesheet, the small script that runs this site and the demo are all served from this domain. The 404 page is served by GitHub Pages itself.
  • Server logs are GitHub's, not ours: GitHub Pages records requests as part of operating the service, under GitHub's privacy statement. The project owner can see aggregate traffic counts GitHub chooses to report; no page of this site adds any tracking of its own on top.

The application

ICE JARVIS runs on your computer. It has no telemetry, no accounts, no crash reporting and no analytics — and that is a property of how it is built, not a policy that could change quietly in a release.

  • Your files stay yours. API keys live in config/api_keys.json inside the app folder, memory in memory/, logs in logs/. They are plain files on your disk. They are not part of any release payload and the build refuses to publish if it finds a secret in what it is about to ship.
  • Four kinds of outbound request, and no others — the AI provider you configure (the conversation you are having, so it can be answered), the public update manifest on GitHub when the app checks for a new version, keyless public data feeds when you ask a question about the world, and your own mail server if you set mail up. Nothing about you or your machine is attached to any of them.
  • Microphone and screen access are yours to switch off, in the interface and in ⚙ Settings; Windows' own permission gates apply to the app like any other program. Audio is turned into the text of your request; it is not stored or uploaded anywhere else.
  • Deleting your data is deleting files. Remove config/api_keys.json and memory/long_term.json for a clean slate, or uninstall — which asks first and defaults to keeping your data.
The readme's privacy section lists every requested endpoint by name, including the OAuth token endpoints a mail sign-in adds and the public feeds the world-data features read.

Downloads and updates

Downloads go straight from this site's links to the project's own GitHub releases. There is no download counter of our own, no redirect service and no intermediary.

  • Every release publishes its SHA-256 checksums in SHA256SUMS.txt, so you can verify that what you received is what was built. How to check.
  • Updates are opt-in. The app reads a small public JSON manifest, compares versions, and only downloads if you agree. The downloaded payload is hashed and verified before it is staged, and applied on the next restart.
  • An update touches no user data. The payload deliberately contains no keys, memory, logs or certificates, so upgrading cannot overwrite them.

Advertising

There is no advertising on this site, and no ad network is loaded by any page. The ad slot wired into the landing page stays hidden and empty until a publisher ID is deliberately configured, which is not the case today.

If advertising is ever enabled, then before it goes live this page will be updated to say so plainly, naming the network and the cookies it sets, and the ad units will be labelled as advertisements. Until this page says otherwise, there is nothing to disclose — and if you would rather the project earned nothing than tracked you, the honest way to support it is a star or a good bug report.
