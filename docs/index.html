What it does

Everything runs locally — the only network calls it makes are to the AI model you configure.

🎙️Talks like a person

Natural conversation in English, Hindi and Hinglish. It hears pauses, hears emotion, and answers out loud with a voice you pick.

🖱️Controls your PC by voice

Mouse, keyboard, windows, typing, apps — full desktop automation. "Open Chrome and search for flights" is one sentence.

🧠Remembers on your disk

Long-term memory, preferences and context live in local files you can open and read. Wipe them anytime; they never leave the machine.

🤖Autonomous mode

Give it a goal and a time budget; it works, reports what it did, and stays inside the limits you set.

🔌Plugins & mail

Gmail and Calendar sign-in with Google OAuth, WhatsApp, YouTube, weather, notes — and a documented plugin API to add your own.

🪟A face that reacts

A living avatar that breathes, listens and reacts to its voice — the one animating above is the shipped UI, not a mockup.

Install in three steps

The installer does everything — no Python, no commands, no admin prompt.

Download the installer

ICE-Setup.exe (~119 MB). If SmartScreen asks, choose More info → Run anyway — the build is reproducible from source.

Double-click it

Installs for the current user, adds ICE JARVIS to the Start Menu, and shows up in Settings → Apps so it can be removed the normal way.

Add a free key

First launch opens setup: paste a free Gemini API key (~1 minute). That's the whole setup.

Prefer source? It's Python — no build step:

# requires Python 3.13 or 3.14
git clone https://github.com/idkunknown657-cell/ICE-JARVIS.git
cd ICE-JARVIS
setup.bat        # Windows — installs everything and starts ICE

Private by architecture

  • Keys, memory, conversations stay on your disk — plain files in the app folder, nothing synced, nothing phoned home.
  • No telemetry, no accounts, no cloud — the only outbound calls go to the AI endpoint you configure yourself.
  • Updates are opt-in and verified — the app checks a manifest you can point anywhere, verifies the SHA-256, and never deletes your data when updating.
  • Open source, CC BY-NC 4.0 — read every line before you trust it.

Build it, check it, break it

Releases are built by GitHub Actions from tagged commits: PyInstaller freeze, Inno Setup installer, selftest of the packaged app, then the exe is published automatically.
