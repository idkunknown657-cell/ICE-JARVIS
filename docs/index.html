What changed in v1.2.0

Every release is built by GitHub Actions from a tagged commit, then verified before it is published. This one teaches JARVIS two things it could not do before: write itself a new tool, and repair its own crashes.

It can learn a skill you ask for

Ask for something it cannot do — “learn how to check my internet speed” — and it writes the tool, proves it works, and answers your original request with it. No restart, no plugin hunting. You can also just ask “what have you taught yourself?”.

Nothing runs until it passes the gate

Generated code is screened for the things it must never do — repartition a disk, touch System32, read your API keys, install itself at login — then executed once in a separate interpreter with a trimmed environment and a hard timeout. It never touches the running app until that passes. It also never installs packages on your behalf.

A crash becomes a fix you approve

When something breaks, it reads the traceback, finds the failing line in its own files, writes the smallest fix and puts it on screen for you to confirm. Library frames are skipped, a backup is taken first, and a patch that does not compile is rolled back on the spot. You can switch off the asking — or never allow it at all.

It survives its own mistakes

The one failure it cannot repair from inside is a patch that stops it starting. So applying a patch arms a watch that is only retired once a session actually comes up — if it never does, the previous version is restored before anything else loads.

Instructions it actually keeps

“Always open links in Chrome”, “reply in Hindi”, “never move files out of my Downloads folder” — stated once, followed from then on, and listed so they can be switched off or deleted by name. Password-shaped text is refused outright, because these ride in every prompt.

348 new tests, all about the refusals

1667 tests on Python 3.13 and 3.14, plus a smoke test of the packaged JARVIS.exe before anything ships. The new ones are mostly about what must not happen: a destructive skill, a patch whose target appears twice, a name collision that must never overwrite a working plugin.

What it does

Everything runs locally — the only network calls it makes are to the AI model you configure.

🎙️Talks like a person

Natural conversation in English, Hindi and Hinglish. It hears pauses, hears emotion, and answers out loud with a voice you pick.

🖱️Controls your PC by voice

Mouse, keyboard, windows, typing, apps — full desktop automation. "Open Chrome and search for flights" is one sentence.

🧠Remembers on your disk

Long-term memory, preferences and context live in local files you can open and read. Wipe them anytime; they never leave the machine.

🤖Autonomous mode

Give it a goal and a time budget; it works, reports what it did, and stays inside the limits you set.

🔌Plugins & mail

Gmail and Calendar sign-in with Google OAuth, WhatsApp, YouTube, weather, notes — and a documented plugin API to add your own.

🪟A face that reacts

A living avatar that breathes, listens and reacts to its voice — the one animating above is the shipped UI, not a mockup.

🌍Answers about the real world

Live aircraft, earthquakes, natural events and satellites, read directly from public feeds — no account, no key, nothing stored.

📈Trading & market analysis

Indicators, backtests, order-flow reads and a paper journal — analysis on your machine, with risk limits you define.

📱Phone dashboard

An optional local dashboard, served over TLS from your own PC with an AES-encrypted channel, so you can reach JARVIS from the couch.

Install in three steps

The installer does everything — no Python, no commands, no admin prompt. The full guide has screenshots-of-truth: what SmartScreen says, how to verify the download, and how to uninstall cleanly.

Download the installer

ICE-Setup.exe (~119 MB). If SmartScreen asks, choose More info → Run anyway — the build is reproducible from source, and the SHA-256 to check it against is published with every release.

Double-click it

Installs for the current user, adds ICE JARVIS to the Start Menu, and shows up in Settings → Apps so it can be removed the normal way.

Add a free key

First launch opens setup: paste a free Gemini API key (~1 minute). That's the whole setup.

Prefer source? It's Python — no build step:

# requires Python 3.13 or 3.14
git clone https://github.com/idkunknown657-cell/ICE-JARVIS.git
cd ICE-JARVIS
setup.bat        # Windows — installs everything and starts ICE

Check what you downloaded

You should not have to trust a download link. Every release ships SHA256SUMS.txt beside the installer, so you can prove the file you have is the file that was built.

One command, Windows

certutil -hashfile ICE-Setup.exe SHA256 — compare the result to the line in SHA256SUMS.txt. Same hash, same bytes.

Or in PowerShell

(Get-FileHash .\ICE-Setup.exe -Algorithm SHA256).Hash — case-insensitive comparison is fine here.

Private by architecture

  • Keys, memory, conversations stay on your disk — plain files in the app folder, nothing synced, nothing phoned home.
  • No telemetry, no accounts, no cloud — the only outbound calls go to the AI endpoint you configure yourself.
  • Updates are opt-in and verified — the app checks a manifest you can point anywhere, verifies the SHA-256, and never deletes your data when updating.
  • Open source, CC BY-NC 4.0 — read every line before you trust it.
