Install on Windows

One file, two minutes, no administrator prompt and no Python. This page is the long version — including the two places people usually trip: SmartScreen, and the API key on first launch.

1 · Run the installer

Download ICE-Setup.exe and double-click it. That link always points at the newest published release, so it never goes stale.

  • Installs for the current user only — no UAC prompt, nothing machine-wide, no services.
  • Start Menu group with ICE JARVIS, ICE JARVIS (debug console), and uninstall.
  • Optional desktop shortcut, placed on whichever desktop Windows really uses — including a redirected OneDrive one.
  • A real entry in Settings → Apps, with icon, publisher, version and copyright in the file properties.
  • WebView2 is installed only if your machine is missing it; without it there would be no window at all.
Prefer not to install? The release also carries ICE-JARVIS-Windows-x64.zip (~160 MB) — unpack it anywhere and run JARVIS.exe. Same app, no registry entries, portable-style.

2 · If SmartScreen complains

Windows shows a blue “Windows protected your PC” panel for any executable it has not seen enough times — a brand-new release of a small open-source project is exactly that. It is a reputation warning, not a virus detection.

  • Click More info, then Run anyway. The install proceeds normally.
  • Or check the file first so you never have to take our word for it — see Verify a download.
  • Don't want to touch it at all? Use the source route: you read and run the code yourself.
Be honest with yourself about links. Only download from the repository's own releases page or from this site. Anyone can re-host an exe under a similar name.

3 · First run

Launch ICE JARVIS from the Start Menu. The window opens on the setup screen, and it wants one thing: an API key.

# the free one, about a minute:
https://aistudio.google.com/apikey
  • Paste a Gemini key — free tier, no credit card.
  • Or paste free fallback keys — GROQ, Cerebras, OpenRouter, Hugging Face; add any subset.
  • Or press Initialise systems with nothing — the app still starts and says “API key required. Open Settings → API Keys.” until you add one.

Keys can be changed, tested, disabled or deleted later in ⚙ Settings → API Keys — no reinstall, no file editing. They are stored in config/api_keys.json inside the app folder, which never leaves your machine and is never part of a release.

If the microphone seems dead

Open ⚙ Settings → Voice & Language → Test. It measures real audio instead of just listing devices, and names the actual failing link: the Windows privacy gate, another app holding the device, an exclusive-mode format, or simply no signal. There is a one-tap button that opens Windows' microphone permissions page.

4 · Updating

JARVIS checks a small JSON manifest when it starts, and only when you let it. The manifest points at the release zip and carries its SHA-256, so a staged download is verified before it is ever applied.

  • Updates are applied on restart, by a short script that waits for the app to exit rather than swapping files under a running process.
  • Your data is untouched. The payload contains no user data at all — no keys, no memory, no logs, no certificates — so there is nothing for an update to overwrite.
  • Nothing is deleted. The copy is additive and merges over the install; removed files stay removed only where the app never wrote them by hand.
  • The old executable is kept as JARVIS.exe.bak until the new one has started successfully.
Manifest URL: https://github.com/idkunknown657-cell/ICE-JARVIS/releases/latest/download/update.json — you can read it with a browser, and point the app at your own copy if you would rather host it yourself.

5 · Uninstalling

Uninstall from Settings → Apps → Installed apps → ICE JARVIS, or from the Start Menu group. It asks before it takes anything with it, and the default answer is keep my data, so a silent or scripted uninstall cannot destroy your keys and memory by accident.

  • Keep data (default) — your config/, memory/ and logs/ stay put for a reinstall.
  • Remove everything — the app folder is deleted, including keys and memory.
  • Want a clean slate without uninstalling? Delete config/api_keys.json and memory/long_term.json; the app runs first-time setup again.

Run it from source

The code is the app. If you have Python 3.13 or 3.14 (64-bit, Add to PATH ticked at install time), there is no build step at all.

git clone https://github.com/idkunknown657-cell/ICE-JARVIS.git
cd ICE-JARVIS
setup.bat        # Windows: finds Python, installs deps, checks config, starts ICE

Prefer a terminal and full control? python setup.py does the dependency install only. Then:

LauncherConsoleUse it when
main.pywhiddenNormal daily use — errors go to logs/jarvis.log
start_debug.batvisibleSomething is misbehaving — every print and traceback, live, and in the log
python -m unittest discover -s testsvisibleYou want to see the 1297 tests pass on your own machine
Building your own installer is possible too: installer/build_installer.py freezes the app with PyInstaller and compiles ICE-Setup.exe with Inno Setup. It refuses to build if it finds a secret in what it is about to ship.

Troubleshooting

ProblemWhat to do
“Windows protected your PC”More info → Run anyway. It is a reputation prompt, not a detection. Check the SHA-256 if you want certainty.
It starts, nothing happensRun ICE JARVIS (debug console) from the Start Menu — same app with output attached. A startup crash also writes logs/startup-crash.log and says so in a dialog.
No reply to your voiceCheck the mic tile on the Home screen (click to unmute), then Settings → Voice & Language for the right input device and a working key.
No speech outputSettings → Voice & Language → pick another output voice. Some voices need an app restart.
Answers are slow or stopThe free tiers rate-limit. Add a fallback provider key; JARVIS moves to it automatically instead of failing.
Mouse clicks land off-targetSay “move mouse to center”, then “mouse position” to recalibrate. Scaled displays (125 %/150 %) are handled automatically.
Desktop shortcut missingOneDrive redirects the Desktop — the shortcut was created on the real one, which may be under OneDrive\Desktop.
